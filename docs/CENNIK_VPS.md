# Развёрнутый Cennik — 28 октября 2026

Адрес: **https://205.172.56.135:8443**. SSH: `cennik@205.172.56.135`, порт 2222.
Ключи находятся в исключённой из Git папке `vps/` на исследовательском ПК:
`cennik_ed25519` — SSH, `owner-key.txt` — вход владельца в веб. Не раздавать их
сборщикам: для Collector и Worker выдаются отдельные ключи в панели.

На Ubuntu 22.04 установлен отдельный Python 3.12.16 в `/opt/cennik/python`,
окружение — `/opt/cennik/venv`, приложение — `/opt/cennik`.
Существующий сервис `cennik.service`, Docker, `/project` и локальные рабочие базы
не изменялись. Новая серверная папка — `/var/lib/cennik-server`.

## Службы и настройки

- `cennik-server.service`: приложение на `127.0.0.1:8770`, автоматический запуск.
- `cennik-web.service`: Caddy 2.11.7, HTTPS, автоматический запуск.
- `/etc/cennik/server.env`: ключ владельца и внешний адрес, права 600.
- `/etc/cennik-web/Caddyfile`: прокси, HTTP → HTTPS с внешним портом 8443.
- `/var/lib/cennik-caddy/production`: рабочие сертификаты и состояние ACME.

Выдан доверенный сертификат Let's Encrypt для IP, профиль `shortlived`.
Caddy автоматически продлевает его через HTTP-01: **внешний TCP 80 должен оставаться
доступным и вести на порт 80 Ubuntu**. HTTPS доступен снаружи на 8443; внутренние
слушатели Caddy настроены на 443 и 8443. Порт приложения 8770 наружу не открыт.

```sh
sudo systemctl status cennik-server cennik-web --no-pager
sudo journalctl -u cennik-server -n 100 --no-pager
sudo journalctl -u cennik-web -n 100 --no-pager
curl --fail https://205.172.56.135:8443/healthz
```

Для обновления кода сначала сохранить резервную копию серверной папки с
остановленным `cennik-server`, затем установить новую версию в его окружение.
Подробности: [инструкция сервера](CENNIK_SERVER.md).
