# Примеры ответов AHledger: PvP Alliance US

Отдельный скрипт для изучения публичного API. Не использует настройки Cennik,
не открывает DuckDB, ничего не меняет в игре и не отправляет данные на сервер.
Нужен Python 3.10 или новее, сторонние библиотеки и API-ключ не нужны.

Скрипт подготовлен **без запуска и тестов**, по
[официальной документации](https://ahledger.com/developers). Доступность ответов
и наличие истории будут известны только после первого запуска.

## Запуск вручную

Откройте `run.cmd` двойным щелчком. Он использует `venv` проекта, а при его
отсутствии — установленный Windows Python Launcher (`py -3`). В конце окно
останется открытым. Это одноразовая выгрузка, фонового процесса и расписания нет.

Либо из PowerShell:

```powershell
Set-Location 'C:\PythonProjects\Cennik'
& '.\venv\Scripts\python.exe' '.\ahledger_export\export.py'
```

Явно выбрать предмет или дополнительные профессии можно так:

```powershell
& '.\venv\Scripts\python.exe' '.\ahledger_export\export.py' --item-id 2589 --profession Tailoring --profession Alchemy
```

Рынок зафиксирован: `forever.pvp.alliance.us`. По умолчанию выбирается лён
(`#2589`), если в текущей таблице есть его количество и цена выкупа. Иначе
скрипт выбирает другую распространённую ткань, затем предмет с наибольшим
доступным количеством. Запросы карточки, подсказки и истории выполняются **только
для одного выбранного ID**, без перебора всего каталога. Причина выбора записана
в `manifest.json`. Наличие текущей цены не гарантирует длинную историю;
если таблицу получить не удалось, используется #2589 с предупреждением.

## Что сохраняется

Каждый запуск создаёт новую папку `exports/<дата_UTC>_<уникальный_суффикс>/`.
Старые выгрузки не перезаписываются. По умолчанию это **18 отдельных ответов**,
покрывающих все 13 маршрутов из таблицы публичного API:

| Маршрут | Файл относительно папки запуска | Выборка |
| --- | --- | --- |
| `/health` | `system/health.json` | Состояние сервиса |
| `/v1/markets` | `system/markets.json` | Справочник доступных рынков |
| `/v1/pricetable/{market}` | `market/pricetable.json` | Компактная таблица цен выбранного рынка |
| `/v1/items/{itemId}` | `item_<ID>/details.json` | Один предмет, `game=forever` |
| `/v1/tooltip/{market}` | `item_<ID>/tooltip.json` | Только выбранный ID |
| `/v1/prices/{market}/{itemId}` | `item_<ID>/prices_24h.json`, `prices_7d.json`, `prices_30d.json`, `prices_90d.json` | Все четыре диапазона для одного предмета |
| `/v1/deals/{market}` | `market/deals_saving.json`, `deals_discount.json`, `deals_sales.json` | Три сортировки, до 200 результатов каждая |
| `/v1/crafting/{market}` | `crafting/01_tailoring.json` | Tailoring, включая неоценённые рецепты (`all=1`) |
| `/v1/structure/{market}` | `market/structure.json` | Один ответ со штатным ограничением API |
| `/v1/signals/{market}` | `market/signals.json` | Пример: `discount=20`, `days=7` |
| `/v1/disenchant/{market}` | `market/disenchant.json` | `all=true`, штатное ограничение API |
| `/v1/economy` | `economy/global.json` | Общая экономика; маршрут возвращает несколько рынков |
| `/v1/economy/{market}` | `economy/market.json` | Экономика PvP Alliance US |

Это обзор маршрутов с указанными параметрами, а не все комбинации фильтров
и не полный архив. Для crafting по умолчанию взята одна профессия; каждый
дополнительный `--profession` добавляет отдельный файл и запрос. Название
профессии и все параметры есть в URL в манифесте. Серверные `filters`, `notes`,
ограничения и временные метки сохраняются в ответах. Неизвестная пагинация
не выдумывается. Глобальные справочники и глобальная экономика сохраняются
целиком, поскольку это отдельные маршруты без фильтра выбранного рынка.

JSON сохраняется с отступами, читаемым Unicode и исходной структурой ответа,
без JSON внутри строк. Десятичные числа сохраняются без преобразования во
float. Единственное преобразование формата — AHL1: текстовая таблица становится
JSON-массивом `rows` с подписанными колонками, исходной меткой времени и
проверенным количеством строк. Цены остаются в меди; пустые значения — `null`.
`salesPerDayX10` сохраняется, рядом добавляется точная величина
`salesEstimatedPerDay = salesPerDayX10 / 10`. Это оценка источника, а не сделки.

`completed` означает, что все запросы успешно сохранены. Это **не** подтверждение
полноты рыночных данных: ответы могут быть ограничены сервером, пустыми или
относиться к разным моментам. Ориентируйтесь на `pricesAsOf`, `generatedAt`,
`observedAt`, `marketStatus`, `filters`, `notes` внутри конкретного ответа.

Закрытые загрузочные маршруты, HTML-страницы, каталог всех предметов и варианты
ответов CSV не обходятся. Данные выгрузки игнорируются Git локальным `.gitignore`.

## Журнал и проблемы

- `export.log` — ход запросов, HTTP-коды, размер ответа, время, повторы и ошибки
  со стеком; те же сообщения видны в окне запуска.
- `manifest.json` — параметры запросов, попытки, безопасный набор HTTP-заголовков
  (включая Cache-Control и ETag), имена сохранённых файлов, предупреждения и итог.
  Обновляется по ходу работы, поэтому остаётся и при прерывании.
- `errors/` — отдельные JSON-отчёты о неудачных маршрутах. Вместо большой
  HTML-страницы ошибки сохраняется лишь короткий фрагмент; JSON-ошибка сервера
  сохраняется структурированно. Ошибочный ответ не выдаётся за успешную выгрузку.

Запросы последовательные с интервалом минимум 2,2 секунды. Временные ошибки
сети, HTTP 408/429/500/502/503/504 повторяются до четырёх попыток. `Retry-After`
учитывается для всей оставшейся очереди. Если сервер требует паузу более
120 секунд, запрос помечается ошибкой; новые запросы во время этой паузы не
выполняются. Тайм-аут сетевой операции — 45 секунд, размер ответа ограничен
64 МиБ, в том числе после распаковки gzip. Запись JSON — через временный файл
с последующей заменой, чтобы частичный файл не выглядел готовым.

Повторного опроса в одном запуске нет, кроме повторов временно неудачных запросов.
Между запусками кэш не используется: перед повторным запуском учитывайте TTL
из `Cache-Control` предыдущей выгрузки; для рыночных ответов дайте пройти хотя бы
минуте. Точная длительность зависит от сервера, ориентир при успешных ответах —
около минуты. `Ctrl+C` прерывает выгрузку, уже записанные файлы остаются.

Коды выхода: `0` — все ответы сохранены; `1` — ошибки/частичная выгрузка;
`130` — остановлено пользователем. При ошибке сначала смотрите `export.log`
и `manifest.json`, затем соответствующий файл в `errors/`.
