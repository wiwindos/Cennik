# Cennik Collector 0.6.0 — приложение для сборщиков

Отдельный Windows x64 EXE, работающий в трее. Python на компьютере сборщика не
нужен. Приложение не открывает веб-интерфейс владельца, стратегии, закупки,
производство и финансовый учёт. Аддон работает в режиме `collector_only`.

В комплект входит CennikAddon 0.22.0 — та же версия, что в Worker 0.6.0. Язык игровых названий определяется автоматически; [подробнее](CENNIK_GAME_NAMES.md).
Режим сборщика сохраняет только сбор, статусы и диагностику; возможности
владельца и персональные планы прокачки профессий в нём недоступны.

## Первый запуск

1. Владелец выдаёт адрес сервера и личный ключ участника. Административный ключ
   участнику не передаётся. Удалённое подключение требует HTTPS.
2. Запустить `dist/CennikCollector.exe`, проверить найденную папку игры либо
   выбрать её вручную. В ней должны находиться `Interface/AddOns` и установленный
   Auctionator. Следить приложение будет за сохранениями всех аккаунтов в этой
   папке игры; выбирать персонажей вручную не нужно.
3. Ввести адрес и ключ, нажать **«Сохранить и установить аддон»**. Устанавливается
   только CennikAddon, прежние его файлы сохраняются в ZIP. Auctionator не меняется.
4. По желанию включить **«Запускать с Windows и работать в трее»**. По умолчанию
   автозапуск не включён; используется только Run текущего пользователя Windows.
5. Полностью перезапустить игру. Далее приложение можно свернуть в трей.

При повторном сохранении настроек пустое поле ключа сохраняет прежний ключ для
того же сервера. При смене сервера нужен новый ключ. Для обновления аддона из
нового EXE снова нажать кнопку установки и перезапустить игру.

Полный сервер предоставляет каталог рынков и имён игровых серверов. Однозначная
привязка персонажа выполняется автоматически по имени сервера и фракции. Ключ
сборщика может быть закреплён за конкретным рынком. Неизвестная или неоднозначная
привязка блокирует сбор; владелец уточняет каталог. NPC аукциона подтверждается
отдельно: [порядок подтверждения](CENNIK_AUCTIONEERS.md). Старый самостоятельный
приёмник без каталога сохраняет совместимость с прежним профилем Alliance PvP US.

## Повседневная работа

Закрытие окна скрывает приложение в трей. Клик по значку открывает окно; меню
позволяет открыть окно, приостановить работу, скопировать отчёт или завершить
приложение. Повторный запуск EXE открывает окно существующего экземпляра.

Виден статус приложения, причина ошибки, очередь отправки и последнее подтверждение
сервера. Отдельно показаны код и расшифровка **последнего сохранённого состояния
аддона с датой**: это не прямое наблюдение за памятью игры. Отчёт поддержки содержит
версии, ID, коды и счётчики, без ключа, имён персонажей, путей и финансового журнала.

Во время игры собираются аукцион, открытые NPC, доступные рецепты, фактические крафт
и распыление. Стратегии и закупки Cennik недоступны; финансовые события в режиме
сборщика не записываются. Существующая история при переключении не удаляется.

Игра записывает SavedVariables после `/reload` или штатного выхода. Приложение
ждёт стабильного файла, читает литеральные Lua-данные без выполнения Lua и кладёт
только публичные наблюдения в надёжную очередь. Новые сохранения отправляются без
ожидания следующего heartbeat. При сетевой ошибке очередь сохраняется и действует
задержка повторов. **«Повторить отправку»** позволяет запросить повтор сейчас.

После локального сохранения публичных данных в очереди подтверждение освобождает
очередь аддона при следующем `/reload`. Подтверждение сервера освобождает очередь
приложения. Отклонённые сервером записи сохраняются отдельно и дают видимую ошибку.
Справочник одобренных аукционистов скачивается автоматически и применяется игрой
после `/reload`. Неизвестные аукционы заблокированы, межфракционные идут в архив.

Пауза сразу останавливает чтение новых сохранений и отправку приложения.
Остановка сбора внутри игры применяется после загрузки обновлённого импорта
через `/reload`; сам аддон также можно приостановить в `/cennik collector`.

## Профиль и совместимость

По умолчанию файлы находятся в `%LOCALAPPDATA%\CennikCollector`. Это отдельные
JSON-файлы, очередь, подтверждения и резервные ZIP аддона; SQL-базы не создаются.
Для тестирования можно передать `--root <другая папка>`.

Аддон, подключённый к рабочему Cennik владельца или другому профилю сборщика,
автоматически не перезаписывается. Не подключайте два разных приложения к одной
папке аддона. Приложение не редактирует SavedVariables игры.

Для раздачи достаточно EXE: аддон и Python уже внутри. Ключ участник вводит сам.
Не раздавайте свой профиль, `connection.json`, тестовые профили или резервные копии.
Рядом со сборкой есть SHA-256 и уведомления о сторонних компонентах; уведомления
также включены внутрь EXE. Подписанного установщика и автообновления пока нет.

## Сборка и проверка

Из окружения разработки на Windows:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.collector.lock.txt
$env:PYTHONPATH = "$PWD\src"
.\venv\Scripts\python.exe tools/build_collector.py
```

Результат: `dist/CennikCollector.exe`. `start_collector.cmd` запускает этот EXE,
а при его отсутствии — исходное приложение через `venv/pythonw.exe` с установленными
зависимостями сборщика. Рабочие базы, настройки и реальные импорты в EXE не входят.

Сквозной тест использует отдельные профили, фиктивную игру и настоящий локальный
HTTP-приёмник. Проверяет EXE, трей, очередь, скачивание реестра и возврат ACK:

```powershell
.\venv\Scripts\python.exe tools/check_collector_desktop.py --exe dist/CennikCollector.exe --output outputs/collector-exe-check
```

Каталог результатов должен быть новым. Для этой проверки дополнительно нужны
зависимости разработки и веб-сервера. Совместимость с настоящим клиентом Forever
нужно проверить в игре; тестовый приёмник не является публичным развёртыванием.
