## Что сделать владельцу

1. Войти в хаб → Cennik → открыть рабочий профиль. В «Источники» ввести токен AHL.
2. В Worker **0.5.0** указать **https://205.172.56.135:8444** без `/cennik/`.
   Старый ключ убрать → «Сохранить и установить аддон» → подтвердить код в вебе.
3. Для Collector **0.5.0** адрес **https://205.172.56.135:8444/collect**,
   нужен новый личный ключ сборщика. Актуальные EXE находятся в локальном
   `release/forever-ready/clients/` и серверном
   `/home/webbox/cennik-release-20261103/clients/`.
4. Аддон **0.21.0** и совместимый Auctionator. Перезапустить игру, выбрать роли
   персонажей. `/reload` → дождаться Worker → ещё `/reload`.
5. На открытии выбрать настоящий рынок AHL. Явное имя realm берётся из API при
   наличии; иначе его подтверждает первый персонаж обновлённого аддона.
   Подтвердить NPC, дождаться Cennik «Полный снимок готов», выполнить `/reload`.
6. Возможности → bulk у аукционера → уточнение в вебе → крафтеру самостоятельная
   закупка → его `/reload` → «Производство / крафт».

Публичный AHL во время проверки вернул пустую/неполную таблицу цен и ограниченную
выборку части рецептов. Это отображается в «Источники». Бета остаётся в расчётах;
неполный ответ не объявляется полным справочником. FYI проверен, содержимое не изменилось.

## Обслуживание

```sh
cd /opt/goldscope
docker compose -f compose.yaml -f deploy/compose.webbox.yaml -f deploy/compose.cennik.yaml --profile ip ps
docker compose -f compose.yaml -f deploy/compose.webbox.yaml -f deploy/compose.cennik.yaml --profile ip logs --tail=100 cennik
```

При обновлении сохранять весь `/var/lib/cennik-server`, `.env` и данные хаба.
Не повторять очистку/prepare и не запускать два Cennik на одном каталоге.
Нельзя публиковать вывод полного `docker compose config`: он содержит секреты.

`/home/webbox/cennik-release-20261103`; журналы развёртывания и нагрузки —
