# Прокачка профессий

Отдельный раздел веба сравнивает закупку ингредиентов на аукционе и три способа
реализации результата: аукцион, продажа NPC, распыление и продажа материалов.
Обычный список прибыльных возможностей и его фильтры не изменены.

1. Установить CennikAddon 0.20.0 через обновлённый Worker и полностью перезапустить
   игру для загрузки нового файла из TOC.
2. Войти нужным крафтером Worker, открыть каждую профессию. Данные считываются
   автоматически; повторить можно через меню под миникартой «Обновить данные
   профессий» или `/cennik professions`. Убрать фильтры и раскрыть категории для
   полного покрытия. Частичное окно не стирает ранее сохранённые рецепты.
3. Выполнить `/reload`, дождаться Worker. В вебе выбрать «Прокачка профессий»,
   персонажа, профессию и количество крафтов, нажать «Подобрать варианты».
4. Необязательная галочка включает распыление, если оно наблюдалось у выбранного
   персонажа. Другого распылителя можно выбрать для просмотра, но данный раздел
   не создаёт передачу материалов между персонажами.
5. Для неизученного рецепта можно указать ID предмета-рецепта и/или стоимость
   обучения. Выбирается более дешёвый известный способ; стоимость учитывается
   один раз на партию. Соответствие предмета рецепту и доступность обучения
   подтверждает владелец: общего надёжного справочника этих связей пока нет.
6. Выбрать вариант, указать допустимый убыток партии и отправить крафтеру.
   Существующие задания самостоятельной закупки и производства выполняют план.
   Другие персонажи этот закупочный план не получают. В игре ещё раз проверяются
   цены, объёмы, навык, общий бюджет и допустимый убыток. Покупку подтверждает игрок.

Можно пользоваться только просмотром, вручную указав профессию и навык.
Ручной навык не разрешает отправку неподтверждённого плана персонажу.
Расчёт партии не является маршрутом до целевого навыка. Даже после одного
крафта сложность может измениться; сведения нужно обновлять после повышения.
Оранжевый цвет трактуется как гарантированное повышение на текущем навыке.
Для жёлтого и зелёного точный шанс неизвестен; стоимость очка отсутствует,
пока владелец не задаст свою вероятность. Эта вероятность явно помечена оценкой.
Отсутствующие цены и недостаточный наблюдаемый объём блокируют отправку.
Рыночный минимум не гарантирует продажу партии; распыление имеет случайный выход.

Отчёты и предварительные расчёты хранятся в `profession_leveling/` отдельно по
рынку и персонажу. Изменений SQL-схемы нет; выбранная партия использует имеющиеся
таблицы заданий и JSON-заказ производства. Контракт закупки прокачки имеет
версию 4; отрицательная прибыль разрешена только стратегии `profession_leveling`.
Код TSM не включён: используется независимая реализация через WoW API.
