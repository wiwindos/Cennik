# Forever: подготовленный выпуск для WIW Hub

Этот выпуск устанавливается в отдельный контейнер Cennik. Хаб и Goldscope сохраняют
свои исходники, пользователей, SQLite и контейнер. Сервер автоматически не обновлялся.
ZIP не требуется: загружаются подготовленные папки.

## Что подготовлено

- В WIW Hub добавлен модуль Cennik с отдельным разрешением. Администратор видит
  его сразу; обычным пользователям доступ выдаётся в «Пользователи».
- `/cennik/` и `/cennik/m/<id>/` обслуживаются отдельным процессом через хаб.
  Проверяются текущая сессия и CSRF, внутренние запросы подписываются HMAC
  (метод, путь, время, хэш тела). Ключ владельца браузеру не выдаётся.
- `/bridge/v1/`, `/pair/v1/`, `/collect/` остаются каналами игровых приложений
  с собственными ключами. Адрес Worker — корень HTTPS-хаба, Collector — тот же
  адрес с `/collect`. Порт самого Cennik в интернет не публикуется.
- Все 12 разделов Cennik сохранены. Тема и цвета соответствуют хабу; светлая/тёмная
  тема общая. Стратегии, снайпер, bulk, учёт, производство и прокачка остаются в Cennik.
- Стартовый пакет: предметы, рецепты/реагенты, NPC-цены, фиксированная модель
  распыления, цены аукциона. Манифест содержит версии, счётчики и SHA256.
  Бета-цены исходно **PvP Alliance US**, не EU; интерфейс явно показывает этот факт.
- Полный свежий рабочий срез заменяет бета-цены, включая отсутствие предметов.
  Неполный скан его не заменяет. До свежего среза бета доступна для стратегий и
  отправки кандидатов в bulk; актуальные лоты и расходы проверяются в игре.
- Даты бета-наблюдений не меняются. Бета-рецепты и исторические ориентиры помечены.
  «Работать без AHledger» оставляет собственные данные и включённую стартовую подложку.
- AHL: цены каждые 300 секунд, рецепты/сверка распыления раз в час; FYI раз в час.
  Это интервалы проверок, с учётом кэша, Retry-After и ошибок источника.
- Ошибка/пустые рецепты/несовместимая сборка/сильное сокращение не заменяют
  прежние рецепты. FYI проверяется по структуре, версии и покрытию, не откатывает
  релиз на бету/старую сборку. Отсутствие явной релизной метки не выдаётся за её наличие.
- Модель распыления автоматически **никогда не заменяется**. Сверяются доступные
  входные характеристики/выходы ограниченной выборки AHL. Это не проверка всего
  каталога. FYI используется для NPC-цен и к этой модели не подключается.
- Worker/Collector 0.5.0, аддон 0.21.0. После каждой успешной отправки Space
  выбирается новый интервал 150–400 секунд. Ввод адресный, в выбранное фоновое окно.

## Загрузка на сервер

В `release/forever-ready/` находятся:

- `cennik/` — исходники сервиса, Dockerfile, зависимости и `release-seed/`;
- `hub-integration/` — изменения только хаба, проверяемый установщик и patch;
- `clients/` — актуальные EXE с лицензиями/контрольными суммами и чистый аддон;
- `SHA256SUMS.json` и `RELEASE.json` — проверка состава выпуска;
- `DEPLOY.md` — эта инструкция.

Загрузить `cennik/`, например в `/opt/cennik`. Изменения хаба применить к каталогу
существующего WIW Hub, например `/opt/goldscope`. Не заменять его папку data,
`.env`, сертификаты, compose.yaml и серверные секреты содержимым Cennik.

Установщик хаба сначала проверяет **все** изменяемые исходники по SHA256 и только
потом записывает файлы. Уже установленные совпадающие файлы пропускаются. Если
версия хаба отличается, он остановится до записи: перенести изменения из
`hub-cennik.patch` в соответствующие файлы этой версии, не заменять их вслепую.

```sh
python3 /path/to/hub-integration/apply.py --hub /opt/goldscope
```

В существующий `.env` хаба добавить параметры из `hub-cennik.env.example`:
настоящий HTTPS-адрес хаба с портом, путь к исходникам/данным Cennik, UID/GID
текущего владельца данных, прежний `CENNIK_OWNER_KEY`, новый общий
`CENNIK_HUB_SECRET`. Общий секрет сгенерировать один раз `openssl rand -hex 32`;
он одинаков у двух контейнеров, в аддон и игровые приложения не передаётся.

`CENNIK_UID`/`CENNIK_GID` взять через `id -u cennik` / `id -g cennik`, если
существующие данные принадлежат этому пользователю. Это сохраняет доступ к
прежнему `upstreams/credentials.json` с токеном AHL. Не подменять старый ключ
владельца новым: использовать значение из приватной серверной конфигурации.
У хаба остаются его прежние логины и пароли.

`CENNIK_DATA_DIR` должен совпадать с прежним `--root` сервиса Cennik
(см. `systemctl cat cennik-server`): внутри находятся `markets.json` и `upstreams/`.
В примере путь и UID/GID оставлены пустыми намеренно: Compose потребует их указать.
Новый пустой каталог не содержит прежнего токена AHL.

Пример ниже использует уже существующий вариант `deploy/compose.webbox.yaml`.
Если хаб использует другой вариант edge, сохранить именно его во всех командах.
Встроенный Nginx теперь допускает пакет Cennik до 64 МБ; промежуточный внешний
прокси также должен его пропускать. Большие пакеты проходят через хаб по одному;
занятый приёмник отвечает 429, а приложение сохраняет пакет и повторяет отправку.

```sh
cd /opt/goldscope
docker compose -f compose.yaml -f deploy/compose.webbox.yaml -f deploy/compose.cennik.yaml build app cennik
```

## Однократная очистка тестовых данных — без резервной копии

Сначала остановить старый Cennik, чтобы два процесса не открывали один профиль:

```sh
sudo systemctl stop cennik-server
# Если Cennik уже запускался контейнером:
docker compose -f compose.yaml -f deploy/compose.webbox.yaml -f deploy/compose.cennik.yaml stop cennik
```

Перед очисткой стартовый пакет целиком проверяется по манифесту и моделям.
Команда удаляет внутри `CENNIK_DATA_DIR` только:
`markets/`, `markets.json`, `workers/`, `pairing/`, `collector-archive/`, `forwarding/`.
То есть тестовые рынки, сканы, задания, старые ключи клиентов и очереди переноса.
**Резервная копия не создаётся.** Сохраняются `upstreams/`, внешние переменные
сервера/ключ владельца, весь хаб и Goldscope. Исследовательские локальные базы
этой командой не обрабатываются. Символические ссылки и чужие каталоги отклоняются.

```sh
docker compose -f compose.yaml -f deploy/compose.webbox.yaml -f deploy/compose.cennik.yaml run --rm --no-deps cennik python -m cennik.server.prepare --root /data --package /app/release-seed --reset-test-data --confirm RESET_TEST_DATA
docker compose -f compose.yaml -f deploy/compose.webbox.yaml -f deploy/compose.cennik.yaml --profile ip up -d app cennik edge
sudo systemctl disable cennik-server
```

После запуска проверить `/health` хаба, открыть Cennik через карточку и сверить
счётчики бета-пакета. В `release-ready.json` серверных данных есть результат
подготовки, включая `backup_created=false`. Старый Caddy/маршрут ACME не удаляется:
он может использоваться хабом для продления существующего сертификата.

Очистку не повторять при обычном обновлении: впоследствии достаточно пересобрать
контейнеры. Повторный `prepare` существующего рынка без явного reset отклоняется.

## На открытии Forever — действия владельца

1. Войти в WIW Hub → **Cennik** → рабочий рынок **Forever · PvP · Альянс · EU**.
   Нажать «Обновить список рынков», выбрать настоящий AHL-рынок. Явные realm names,
   если AHL их вернул, привяжутся автоматически. Общая надпись «PvP EU» именем
   сервера не считается; если API не даёт имени, его подтвердит первый персонаж
   обновлённого аддона выбранного рынка. Имя не угадывается из тестового realm.
2. Открыть Worker 0.5.0, выбрать папку **Forever**, адрес корня **хаба**, пустой ключ
   → «Сохранить и установить аддон». Подтвердить код в Cennik для рабочего рынка.
   После очистки старые ключи Worker/Collector больше не действуют.
3. Полностью перезапустить игру. В двух персонажах выбрать «Аукционер» и «Крафтер»
   через меню Cennik. У каждого `/reload` → дождаться Worker → ещё `/reload`.
   Один Worker обслуживает два аккаунта одной папки игры. Смена роли доступна
   позже после остановки автоцикла и завершения активных заказов.
4. Крафтер: открыть профессии, убрать скрывающие фильтры и раскрыть категории →
   «Обновить данные профессий» → `/reload`. Так сервер узнает реальные навыки,
   изученные рецепты и возможность распыления.
5. Аукционер: открыть AH и подождать. Предложить тип неизвестного NPC, одобрить
   имя/координаты в вебе, синхронизировать и `/reload`. Дождаться именно Cennik
   **«Полный снимок готов»**, затем `/reload`; проверить подтверждение Worker и
   полный снимок в вебе. Пока AHL пуст, стратегии используют бета-подложку;
   после своего полного снимка — свои актуальные цены. При сбое AHL включить
   «Работать без AHledger», пересчёт запустится автоматически.
6. Возможности → выбрать кандидатов → массовая проверка у аукционера → `/reload`
   → в вебе выбрать подтверждённые варианты → крафтеру «Самостоятельная закупка»
   → дождаться Worker → `/reload` крафтера → меню «Производство / крафт».
   Для возврата результата аукционеру доступны почта/обмен с подтверждением приёма;
   если предметы остаются у крафтера, он может продать их сам с общим учётом.
7. После ручного прогона при необходимости включить автоцикл: выбранное окно,
   макрос `/reload` на F8, игровое «Взаимодействие с целью» на F9, NPC в цели,
   видимый неперекрытый индикатор. Space — отдельная опция Worker 150–400 секунд.
   Реакцию настоящего Forever на фоновые клавиши проверить визуально.

Сборщикам выдавать Collector 0.5.0 и новые персональные ключи. В нём остаются
только сбор и понятная диагностика, торговые разделы сборщикам не выдаются.
Retail/Classic тестируется в отдельном рынке с типом клиента «Тестовый»;
его роли, наблюдения и очереди не назначаются рабочему Forever-профилю.

## Проверки перед передачей

Результаты тестов и ограничения фактического прогона записаны в `VERIFIED.md`.
На этом Windows-ПК нет Docker: запуск Linux-контейнеров и настоящий клиент
Forever требуют финальной проверки после загрузки. Два отдельных HTTP-сервиса,
Chrome и реальные EXE проверяются локально без ввода клавиш в игру.
