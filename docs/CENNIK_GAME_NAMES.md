# Игровые названия RU / EN

В шапке рабочего рынка есть переключатель «Названия: RU / EN». Интерфейс остаётся русским. Выбор сохраняется в браузере отдельно для пользователя хаба. Переключение не запускает пересчёт стратегий.

Аддон 0.22.0 определяет язык через `GetLocale()`. Worker и Collector 0.6.0 передают локаль вместе со сканами, названиями рецептов, реагентов и NPC. Для наполнения словаря нужны обычные сканы аукциона, открытие профессии или торговца, затем `/reload` и успешная отправка приложения.

Для обновления приложения завершите старый EXE через трей, запустите новый, нажмите «Сохранить и установить аддон» и перезапустите игру. Подключение, ключ и роли сохраняются в прежнем профиле приложения.

## Существующая база

- Цены, рецепты, истории, рынки, задания, доступы и привязки сохраняются.
- Словарь — отдельные таблицы `game_names` и `game_names_meta` в существующем `state.sqlite` каждого рынка. Он входит в штатное резервное копирование БД.
- Первый запуск с бета-пакетом автоматически наполняет EN из проверенных AHL-источников и включённой выгрузки: 27 533 названия предметов и 2 168 названий рецептов. Экспорт содержит только ID и названия.
- Бета-пакет смешанный: 2 600 записей предметов пришли из старых игровых сканов. Без достоверной локали они не записываются автоматически в RU или EN. Английские названия по совпадающим ID восстановлены из исходной локальной AHL-базы.
- Новые наблюдения сохраняют язык независимо. Имена предметов со случайным суффиксом не заменяют базовое название предмета. Другие рынки и тестовые клиенты не пополняют словарь рабочего рынка.
- RU наполняется с обновлённых русских клиентов. Для уникальных Forever ID второго названия пока может не быть. Тогда показывается доступное название с `[EN]`, `[RU]` либо `[без перевода]`, если язык старого названия неизвестен. Обычные предметы не сопоставляются с уникальными по похожему названию.
- Поиск предметов работает по обоим языкам и ID. Расчёты, версии рецептов, данные экспорта и привязки используют прежние ID; перевод применяется только в браузере.

Справочник можно воспроизвести командой `venv\Scripts\python.exe tools\export_game_names.py`. Скрипт читает исходную `data/analytics/ahledger.duckdb` без записи и создаёт `src/cennik/reference/game_names.json`. Исходные цены и бета-пакет не изменяются.

API словаря: `/m/<рынок>/api/v2/game-names`, через хаб — `/cennik/m/<рынок>/api/v2/game-names`. Необязательный `revision` позволяет получить короткий ответ, если названия не менялись. Словарь защищён тем же входом, что и рынок.
