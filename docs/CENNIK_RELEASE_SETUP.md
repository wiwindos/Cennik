# Подготовка к открытию Forever

Сервер и исследовательский ПК остаются отдельными. Рабочий веб:
https://205.172.56.135:8443. Worker 0.3.3, Collector 0.4.2, CennikAddon 0.18.1.
Массовые проверки сохраняют прежний ручной запуск; новая массовая автоматизация
и дополнительные операции по образцу TSM в этот выпуск не входят.

## Рынок и свой игровой ПК

1. Войти в главную панель ключом владельца. Нажать «Настроить» у своего рынка,
   выбрать его из списка AHledger. Для другого региона/фракции/типа нужен новый
   изолированный профиль. Список рынков не загружает цены всех серверов.
2. Оставить включённым «Автоматически обновлять цены AHL и пересчитывать
   возможности», сохранить рынок. При недоступности каталога AHL прежний код
   рынка остаётся доступен; имя нельзя угадывать по чужому региону.
3. Установить Auctionator. Запустить Worker, выбрать папку игры и адрес корня
   сервера. Поле ключа можно оставить пустым: «Сохранить и установить аддон»
   покажет восьмизначный код на десять минут.
4. В блоке «Подключить игровой ПК» веба сверить тот же код и подтвердить ПК
   для выбранного рынка. Ни ключ владельца, ни SSH-ключ Worker не нужны.
5. Полностью перезапустить игру. В каждом персонаже выбрать «Аукционер» или
   «Крафтер» кнопкой в окне Cennik. Повторно открыть его можно `/cennik role`
   или кнопкой «Роль этого персонажа» в разделе «Рынок».
6. Сделать `/reload`, дождаться Worker и повторить `/reload`, чтобы игра
   получила адресный импорт. Один Worker обслуживает оба аккаунта одной
   установки игры. Первое однозначное имя сервера от подтверждённого ПК
   привязывается автоматически; неизвестные или несовпадающие имена видны в вебе.

Назначение относится к персонажу, а не ко всему ПК. В одном рынке остаётся один
аукционер, всего до восьми рабочих персонажей. Активные производственные заказы
защищают участников от смены роли. При конфликте сохраняется прежнее назначение,
причина показывается владельцу. Ручная выдача ключа по прежнему сценарию сохранена.

При переносе игры с локального Cennik сначала остановить прежнюю синхронизацию,
сохранить ImportedData.lua и SavedVariables. Worker не перезаписывает чужую
привязку; порядок переноса описан в [Worker](CENNIK_WORKER.md).

## Источники и работа без AHL

В «Настройках» есть скрытое поле токена AHledger с сохранением, проверкой
соединения и удалением. Токен хранится в `upstreams/credentials.json` серверного
профиля с правами 600, используется как Bearer только для API AHledger. В ответы
веба, аддон, Collector и Git он не попадает. Проверка запроса не удостоверяет
повышенную квоту: публичный API может принять запрос и без действующего ключа.

При включённом обновлении цен рецепты AHL проверяются раз в час. История
целей снайпера и рабочих заданий загружается партиями до пяти предметов раз
в десять минут. API-кэш и Retry-After продолжают действовать. Неуспешные
обновления повторяются с паузой; статус виден в «Источниках» и «Настройках».

FYI проверяется раз в час, в том числе при выключенном AHL. Обновление
идёт через ETag, проверку структуры, цен и полноты, затем версионированную
установку. При сбое остаётся прежний каталог; резкое сокращение требует проверки.
Общая загрузка кэшируется для всех рынков. «Проверить каталог FYI сейчас» запускает
проверку вручную. Дата скачивания не делает прежнюю бета-сборку релизной: пометка
снимается только для подтверждённой версии. Наблюдения у NPC сохраняются отдельно.

В «Возможностях» — галочка «Работать без AHledger». Она отключает получение
цен/истории/рецептов AHL и использует собственные снимки и локальную историю.
Сохранённые справочники и полные рецепты из игры доступны. При отсутствии оценки
продаж возможности не отбрасываются только из-за неё, но получают пометку
неизвестной ликвидности. Исторические скидки требуют накопленной истории.
После смены режима нужно пересчитать возможности.

Откройте окна профессий крафтеров и сохраните игру. Для аналитики принимаются
только рецепты с известными результатом, количеством выхода и точным составом.
Неоднозначные альтернативы реагентов и неполные ответы не заменяют известные
рецепты. Современный API читается через GetRecipeSchematic, прежний — через
GetTradeSkillNumMade и список реагентов. Реальную совместимость сборки Forever
необходимо проверить в игре. Правила распыления по-прежнему являются отдельной
версией модели: сверка AHL не подменяет их ограниченным списком возможностей.

## Сканы без reload

Аддон продолжает сбор примерно раз в 15 минут и хранит последние три наблюдения,
с предпочтением полных сканов, до 48 МБ на скан и 128 МБ суммарно в очереди.
При необходимости по объёму остаётся меньше трёх. Старейшие заменяются, счётчик
замен до выгрузки виден в диагностике. Пустой ответ/тайм-аут при полной очереди
не вытесняет готовые полные снимки. Эти данные находятся в памяти игры; аварийный
выход может их потерять. Worker/Collector увидят их после `/reload` или штатного
выхода. Ротация не создаёт непрерывный канал из памяти игры.

Обработка идёт порциями до 500 строк и около 4 мс работы между уступками
управления игре; строки объединяются блоками по 2000. Диагностика показывает
число обработанных строк, процент и объём. Максимум — 2 млн строк / 300 тыс.
вариантов в снимке, если он укладывается в бюджет размера. Предел 48 МБ включает
строки и описания вариантов с запасом на сериализацию, а не только файл данных.
Неполный снимок явно помечается и не становится READY при ожидании следующего
скана. Предыдущие полные снимки не удаляются ради незавершённой попытки.

SavedVariables читается до 256 МБ; парсер обрабатывает длинные строки блоками.
Worker передаёт по одному снимку в пакете до 60 МБ, сохраняет очередь на диск,
продолжает после перезапуска и объединяет подтверждения всех снимков. Файл
считается переданным только после последнего подтверждения. Неизменённое,
уже переданное сохранение повторно не разбирается. Collector также читает
увеличенное сохранение и передаёт отдельные наблюдения.

## Прыжок / Space в фоновое окно

В Worker: «Прыжок / Space…» → выбрать окно WoW из настроенной папки игры →
«Отправить Space сейчас». Галочка включает повтор примерно раз в три минуты.
Кнопка и разрешение в аддоне, проверка пикселей, аукциона и игрового состояния
убраны. Worker проверяет HWND, PID, время запуска и путь EXE и адресно отправляет
нажатие и отпускание Space без переключения фокуса. Активное, закрытое или
перезапущенное окно, пауза приложения и удерживаемые Shift/Ctrl/Alt блокируют
отправку. Свёрнутое окно допускается. После перезапуска игры окно выбирается заново.

Worker подтверждает постановку сообщения Space в очередь окна. Игра может
игнорировать фоновый ввод; фактический прыжок проверяется визуально, Space
должен быть назначен на прыжок. Отправка клавиши сама по себе не доказывает
сброс серверного AFK.
