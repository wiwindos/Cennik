# Исправление регистрации персонажей — 21.11.2026

Worker 0.8.2, Collector 0.6.7, CennikAddon 0.37.0.

При `ADDON_LOADED` клиент иногда возвращает пустой сервер. Аддон раньше выбирал
общий импорт и сохранял неполный профиль, а Worker включал его в общий запрос.
Сервер отвечал HTTP 422, блокируя регистрацию остальных персонажей этого Worker.

В текущем Forever `GetRealmName()` и `GetNormalizedRealmName()` могут оставаться
пустыми после входа, а `GetRealmID()` возвращает 0. Поэтому версия 0.36.0 могла
бесконечно ждать сервер и не показывать Cennik. В 0.37.0 ожидание относится только
к имени персонажа и фракции. Без сервера интерфейс запускается, сбор и покупки
заблокированы до явного подтверждения выбранного рынка.

Кнопка «Подтвердить рынок» сохраняет выбор для GUID и полного имени персонажа.
Используется логический идентификатор вроде `forever-eu-pvp`; это подтверждённый
игроком рынок, а не прочитанное из API название сервера. Другой GUID, фракция или
выбранный в приложении рынок не наследуют подтверждение. Непустой ответ API имеет
приоритет и не заменяется сохранённым выбором. Фамилия Forever учитывается в
полном имени, чтобы персонажи с одинаковым первым именем не смешивались.

Worker пропускает неполные старые профили, не переписывая SavedVariables.
После изменения сохранения новые полные профили автоматически регистрируются.
Старые полные профили, снимки, история, ключи и настройки сохраняются.
Сервер поддерживает логические идентификаторы с прежней проверкой региона и типа
рынка. Финансовая очередь общая для аккаунта: можно передавать события его других
зарегистрированных персонажей на том же Worker. Чужие аккаунты и рынки отклоняются.

## Установка

1. Закрыть все окна WoW и выйти из прежнего Worker через меню трея.
2. Запустить `release/worker-0.8.2/CennikWorker.exe`.
3. Нажать «Сохранить и установить аддон» с прежними настройками. Ключ не менять.
4. Войти в игру и открыть Cennik на аукционе. Если сервер скрыт, проверить рынок
   Forever · PvP · Альянс · EU и нажать «Подтвердить рынок».
5. Выполнить `/reload`, дождаться обмена Worker
   и снова `/reload`, чтобы игра прочитала подтверждение.

Для сборщиков: `release/collector-0.6.7/CennikCollector.exe`; подтверждение через
«Подключение / рынок» в аддоне.
Для ручного обновления аддона есть `release/addon-0.37.0`: копировать поверх
существующего, не удаляя `ImportedData.lua`. Старый Worker тоже надо обновить.

Проверки: задержанная/пустая идентификация, сохранение адресного импорта,
единственный таймер повтора, неизменность роли при временно пустом сервере,
старые неполные профили нескольких аккаунтов, регистрация после готовности,
доставка сканов и готовые EXE на изолированных тестовых настройках.

Дополнительно проверяется постоянно пустой сервер (включая nil/пробелы), доступность
вкладки, подтверждение по GUID, сохранение после reload, запрет наследования
другим персонажем, приоритет реального ответа API, различение фамилий, сохранение
старых сканов того же PvP-рынка и полный серверный обмен с логическим идентификатором.

Старые операции этого рынка с пустым сервером сохраняются без изменений отдельно
в `accounting/unresolved/<SHA256>.json` с причиной и маршрутом доставки. После
успешного сохранения сервер подтверждает доставку этих ID, но не включает их в
остатки, себестоимость или прибыль и не приписывает нынешнему персонажу.
Обычные операции и сканы продолжают приниматься. Повторная доставка не создаёт
копий и не удваивает учёт; непустой чужой сервер/аккаунт по-прежнему отклоняется.
