# Сбор данных — Worker 0.8.0 / аддон 0.35.0

## Обычный сбор: без выбора окна

1. Закройте старый Worker, запустите новый EXE. Настройки и очередь сохраняются.
2. Для обновления аддона закройте игру и нажмите «Сохранить и установить аддон».
3. В игре откройте меню Cennik под миникартой → **Автоскан**.
   Выбор сохраняется отдельно для каждого персонажа. По умолчанию автоскан выключен.
4. Включён: аддон сам запрашивает полный скан при открытом аукционе, соблюдая интервал
   15 минут и ограничения Auctionator/игрового сервера.
   Выключен: свои запросы не запускает; ручные полные сканы Auctionator всё равно подхватывает.
5. Дождитесь **Cennik: Полный снимок готов**, выполните `/reload` или штатно выйдите из игры.
   Worker отправит сохранённые данные всех аккаунтов из выбранной папки игры.
   Следующий `/reload` загрузит подтверждение сервера и уберёт подтверждённые снимки из очереди аддона.

Сохранения WoW записываются на диск только при `/reload` или выходе.
Без этого EXE не увидит новый снимок в памяти игры. Выбирать окно и назначать
производственную роль для обычной передачи не требуется.
Статус EXE различает отправку и обработку на сервере; счётчик показывает снимки,
а не служебные обмены. При ожидании серверного подтверждения большой пакет не отправляется повторно.
Глобальная **Пауза передачи** в EXE приостанавливает отправку. Это отдельная настройка.

## Дополнительно: автоматические /reload и открытие NPC

Первый раз: установите Auctionator, закройте WoW, запустите новый Worker и нажмите
«Сохранить и установить аддон». Назначьте в игре клавиши макросу `/reload` и
взаимодействию с NPC; в Worker укажите эти же клавиши (ваши прежние настройки сохраняются).

1. Worker → **Авто-/reload и NPC…** → выберите окно мышью.
2. При необходимости включите **Также искать по общему списку целей снайпера** → **Запустить**.
3. После первоначальной настройки один раз выполните `/reload` для загрузки режима.

Дальше Worker сам подключает персонажа, сохраняет/синхронизирует данные,
открывает аукцион, снимает полный скан и восстанавливает поиск. Стойте рядом с NPC.
Роль выбирать не нужно. Смена персонажа или аккаунта в выбранном окне запускает
автоматическую синхронизацию; возможны две последовательные перезагрузки UI.
Производственные роли и адресные задания остаются прежними.
В 0.7.1 обновление выбранного персонажа не ждёт фоновых обменов без данных;
сохранение после /reload сразу будит очередь отправки.

После перезапуска игры единственное подходящее окно подхватывается автоматически.
Если окон несколько — выберите нужное. Для автоматических клавиш переключите фокус
на другое окно. WoW должен оставаться видимым, не свёрнутым; его верхний левый угол
не перекрывайте. Клавиши отправляются только выбранному окну.

Поиск сам ничего не покупает. Список целей общий для рынка, покупки подтверждает игрок.
Подтверждённое количество и расходы объединяются после сохранения и обмена с сервером.
Перед работой на другом персонаже Worker дожидается передачи сохранённых данных.
Это не мгновенная связь из игры: покупки в другом несинхронизированном окне ещё не видны.
Неизвестный результат покупки нужно уточнить на том персонаже, где она выполнялась.
Подтверждённые NPC доступны всем; нового аукциониста владелец одобряет в вебе.

**Остановить** прекращает автоматические клавиши. **Продолжить после ошибки** повторяет
проверку после устранения причины. Подробности: отчёт поддержки и последние 200 событий
в `%LOCALAPPDATA%/CennikWorker/auction-cycle-events.json`.
