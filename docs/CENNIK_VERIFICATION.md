# Cennik Core v0.1 — результат проверки

Проверено 11 октября 2026 года. Реализация расширяет текущие FastAPI и веб-панель;
новый пакет находится в `src/cennik/`. Настройки одного активного рынка, история
запусков и возможности сохраняются в отдельной SQLite. Источник открывается только
для чтения. Три стратегии запускаются исключительно вручную; загрузчик AHledger,
восстановление и построение DuckDB не переписаны.

Использована изолированная временная копия
`data/samples/normal-alliance-us/analytics/ahledger.duckdb`.
Активный рынок выбран из реально покрытых рынков базы: `forever.normal.alliance.us`.
Последнее наблюдение: **9 октября 2026, 22:20:28 +05:00**.

- 2958 предметов с наблюдениями.
- **332 ориентировочные возможности:** 17 исторических скидок и 315 крафтов.
- Vendor Arbitrage выполнен, прибыльных кандидатов с известной NPC-ценой нет.
  Для 2863 предметов NPC-цена отсутствует, 92 не прибыльны, у 3 нет положительной
  закупочной цены. Эти случаи отражены в диагностике.
- Повтор идентичного расчёта переиспользует успешный запуск.
- Хеш исходной базы и её копии после расчёта совпадает с первоначальным:
  `386d676cf77ff983d9c38e966c6dfdbb16f525ff9b3cf6a7b85182fd0a034670`.
- Загрузка из AHledger не выполнялась.

Для проверки старой выборки при текущем времени явно установлен увеличенный порог
свежести **31536000 секунд**, только в временном тестовом хранилище. С обычным
порогом 24 часа эти цены устарели и не должны давать актуальные сигналы. Дополнительно
проверен расчёт на времени наблюдения. Более поздно полученные справочники при
таком `as_of` намеренно недоступны; этот режим не является полноценным бэктестом.

Подробный машинный отчёт: `data/reports/cennik-sample.json`.
Снимок интерфейса: `data/reports/cennik-analytics-preview.png`.
Эти локальные артефакты находятся в уже исключённой из Git папке `data/`.

## Ограничения и v0.2

Все результаты имеют статус `indicative`. Агрегированная цена не подтверждает
конкретный лот, объём по минимальной цене, доступ к NPC или продажу результата.
NPC-поля и данные о привязке предметов в выборке неполны. Комиссия включена в
аукционные продажи; потерянные залоги, повторные выставления, изменение цен и
время крафта указаны как исключённые затраты.

Для v0.2 приоритетны реальные сканы лотов с глубиной, подтверждение доступности
рецептов/NPC и журнал исполненных сделок. После появления этих данных можно
добавлять бэктесты, оценку ликвидности и оптимизацию капитала независимыми модулями.
