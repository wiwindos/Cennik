# Cennik: настройка на игровом ПК

Версии: Worker / Collector 0.6.0, встроенный CennikAddon 0.22.0.

## Что передать

- Аукционеру и крафтеру: `dist/worker-0.6.0/CennikWorker.exe`.
- Человеку, который только собирает данные: `dist/collector-0.6.0/CennikCollector.exe`.
- Для запуска достаточно одного выбранного EXE. Python и отдельная установка CennikAddon не нужны.
- Нужны Windows x64, интернет, установленный WoW и совместимый Auctionator. Auctionator устанавливается отдельно.
- Не передавайте свои настройки, ключи и папки с данными приложения.

## Worker: аукционер и крафтер

1. Закройте игру. Запустите `CennikWorker.exe`, выберите папку нужного клиента WoW с `Interface/AddOns` и `WTF`.
2. Адрес сервера: `https://205.172.56.135:8444` — без `/cennik/`. При новом подключении поле ключа оставьте пустым.
3. Нажмите «Сохранить и установить аддон». Полученный код подтвердите в вебе: хаб → Cennik → рабочий рынок → подключение рабочего ПК.
4. Запустите игру, включите Auctionator и CennikAddon. Через меню под миникартой выберите роль каждого персонажа: аукционер или крафтер.
5. Выполните `/reload`, дождитесь обмена Worker с сервером, затем ещё `/reload`, чтобы загрузить ответ в аддон.
6. Аукционер: откройте аукцион. Если NPC неизвестен, предложите его тип в аддоне; владелец подтверждает NPC в вебе по имени и координатам.
7. Дождитесь именно сообщения Cennik «Полный снимок готов», затем выполните `/reload`. Проверьте успешную отправку в Worker.
8. Работа: варианты в вебе → массовая проверка у аукционера → уточнённые результаты → назначение крафтеру самостоятельной закупки → `/reload` крафтера → меню под миникартой → «Производство / крафт».

Одного Worker достаточно для двух аккаунтов в одной папке игры. Роли назначаются персонажам; их можно менять. Для другой папки клиента нужна отдельная настройка.

## Collector: только сбор данных

1. Получите у владельца личный ключ сборщика.
2. Закройте игру, запустите `CennikCollector.exe`, выберите папку WoW.
3. Адрес: `https://205.172.56.135:8444/collect`. Введите личный ключ.
4. Нажмите «Сохранить и установить аддон», запустите игру с Auctionator и CennikAddon.
5. Откройте аукцион, оставайтесь в нём до завершения скана Cennik. Для неизвестного NPC предложите тип и дождитесь подтверждения владельца.
6. После сообщения Cennik «Полный снимок готов» выполните `/reload`. Приложение отправит сохранённые данные автоматически.

Collector показывает сбор, состояние и ошибки; стратегии и закупки владельца ему недоступны.

## Каждый день

1. Запустите своё приложение и оставьте его работать в трее. Можно включить запуск с Windows.
2. Сканы доходят до приложения после `/reload` или штатного выхода из игры.
3. При ошибке скопируйте отчёт поддержки из приложения и отправьте владельцу. Ключи не отправляйте.
4. При обновлении завершите старое приложение через трей, запустите новый EXE, снова установите аддон его кнопкой и перезапустите игру.

Worker и Collector одновременно к одной папке аддона не подключайте. Для аукционера/крафтера достаточно Worker — он тоже передаёт сканы.
