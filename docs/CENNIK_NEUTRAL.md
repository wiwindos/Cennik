# Межфракционный аукцион

В выбранном рынке Cennik откройте «Межфракционный аукцион».

- «Выгодные сделки» — купить на межфракционном и перепродать на обычном рынке выбранного профиля.
- «Все предметы» — все предметы/варианты с выкупом из последнего полного нейтрального скана, включая варианты без цены продажи или прибыли.
- Нажмите название для расчёта партии и списка целых лотов. Список не отправляется в аддон/снайпер.
- Фильтры: название/ID, прибыль, доходность, бюджет на одну строку и возраст обеих цен. Пустой бюджет — без ограничения, нулевой — без закупки. Возраст 0 — без ограничения, с отметкой устаревания по настройке рынка.
- Таблица обновляется автоматически примерно раз в 10 секунд при открытом разделе. Неотправленный ввод фильтров сохраняется.

Ориентир продажи — минимум положительных текущей минимальной цены, текущей медианы и исторической медианы AHledger 30d. Без текущего наблюдения одна история сделку не создаёт. Для суффиксов/бонусов необходим тот же вариант в собственном скане обычного рынка. Клиентский уровень и отображение ссылки не являются вариантами. Название особого варианта сохраняется в языке исходного скана.

Комиссия берётся из настроек обычного рынка. Каждый выбранный лот прибыльный после комиссии; бюджет ограничивает подбор целых лотов, отсортированных по цене за штуку. Это не оптимизация глобального портфеля: строки могут использовать один и тот же бюджет. Депозит неудачных выставлений, перенос и изменение цен не включены. Спрос — отдельная оценка источника, не гарантия продажи. При неизвестном спросе сделки остаются видимыми.

Исходные нейтральные снимки по-прежнему хранятся в `archive/neutral_auctions` постоянно. При первом открытии раздела старые архивы индексируются. Производные таблицы `neutral_scan_registry` и `neutral_offers` находятся в `market.duckdb`. Рабочие цены, лоты и результаты стратегий обычного рынка не заменяются. Частичные снимки не заменяют полный; неопределённые снимки не участвуют. Новый подтверждённый полный пустой скан очищает нейтральную книгу, поздний старый скан её не восстанавливает.

API только для чтения: `GET /m/{profile}/api/v2/neutral`; доступ через существующую авторизацию Cennik/хаба. Внутри хаба используется префикс `/cennik`. Каждый профиль изолирован. Worker, Collector и аддон для этого раздела обновлять не требуется.

Под исторической ценой показана ликвидность обычного рынка: оценка продаж/сутки, источник и собственная дата этой оценки. Устаревание определяется пределом возраста цен в настройках рынка; свежесть цены не обновляет дату спроса. Для особых вариантов показывается доступная оценка AHledger по предмету с пометкой «все варианты». Это не оценка продаж конкретного суффикса. Цена продажи по-прежнему берётся только из собственного скана того же варианта. Отсутствующая оценка не подменяется нулём и не скрывает сделку; показывается причина отсутствия. В режиме только собственных данных AHL-ликвидность не используется.

Дополнительный отбор: диапазоны продаж/сутки, цены за штуку (выберите покупку или ориентир продажи) и доходности. Пустая граница не ограничивает диапазон. При активной границе продаж неизвестная ликвидность исключается; известный ноль остаётся числом. Сортировать можно по прибыли, доходности, прибыли за штуку, продажам/сутки и обеим ценам в любом направлении. Неизвестные значения идут последними. Все условия и сортировка применяются перед разбивкой на страницы и сохраняются при автообновлении.

Раздел открывается с доступными поиском и фильтрами, пока первый срез готовится в фоне. Данные и карточка предмета появляются автоматически, без повторного нажатия. Расчёт запрашивает цены только нужных предметов; для особых вариантов не загружается общая история цен. При занятой рыночной БД фильтры применяются к готовому сравнению с сохранением исходных дат и предупреждением об обновлении. Изменение режима источников не подменяется старым сравнением с другими источниками.
