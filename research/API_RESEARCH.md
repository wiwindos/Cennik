## Расхождения и полнота

Документация в перечне endpoints называет 24h точками полного скана, а ниже примера JSON совместно с 7d называет его часовым. Фактический 24h — по сканам. Заданные интервалы не считаются гарантированными: сохраняются реальные минимальный, медианный и максимальный шаги и пропущенные buckets.

Каталог не является полным item-details dump: класс задан категорией, колонка 4 — подкласс. Игровой build id отсутствует в JSON; нельзя достоверно приписать всем ответам номер текущего RSS-билда. Имя/качество/уровень/требование/icon/inventoryType сохраняются из каталога; vendorSell дополняется отдельной очередью. Если AHledger не сообщает stack/binding, это NULL, а не догадка.

JSON API содержит дробные производные денежные оценки (пример netValue=75.05 и margin=19.049999999999997). Они сохраняются точно как получены, а целочисленные нормализованные суммы вычисляются через Decimal с округлением вниз, не через float.

В официальном API не описана пагинация crafting/deals/disenchant/structure. Документация предупреждает, что неизвестные параметры игнорируются: выдуманный `offset` создавал бы ложное ощущение полноты. При достижении сообщённого предела выгрузка PARTIAL. Рецептов в других профессиях может быть больше 500; полнота всего рецептурного каталога не подтверждена двумя пробами.

Общий публичный лимит в актуальной developers — 300/мин, market tools — 60/мин. Используется безопасный глобальный 1/сек и суммарный tools 0,5/сек, с Cache-Control и снижением скорости при перегрузке. Не делаются попытки проверить лимит нагрузкой.

Raw scans архивируются на стороне AHledger, но публичная загрузочная ссылка/endpoint не опубликованы в изученной документации. Для полного исторического архива отдельных лотов нужен запрос через [контактную форму](https://ahledger.com/contact). NPC, дропы, квесты, зоны, старые версии предметов и составы recipe diffs также не объявлены доступными как полный публичный bulk API. Они явно помечены недоступными, сайт массово не парсится.

## Границы этого тестового архива

Основной архив содержит только ограниченные реальные ответы исследования. История цен проверена для Linen Cloth на четырёх торгующих Forever рынках; это выборка одного предмета на рынок, а не полная история предметного каталога. Пустой ответ проверен на RP Horde US. Экономика содержит дневные точки четырёх активных рынков; она не заменяет цены всех их предметов.

Фактическая минимальная дата **каждого скачанного набора** вычисляется парсером из ответа; агрегированные границы и пробелы доступны в dataset_metadata и HTML/JSON. Дата начала беты 17 сентября используется для оси отчёта, не как придуманная дата начала данных.
