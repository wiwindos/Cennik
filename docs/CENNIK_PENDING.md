# Отложенные изменения

## Очередь полных сканов — 2026-11-06

По просьбе владельца пока только зафиксировано, без реализации.

В Worker 0.6.4 автоцикл отдельно блокирует новый автоматический запрос при заполнении
очереди по числу или объёму. Общая ротация и отображение статусов ниже остаются отложенными.

- Отправлять все накопленные снимки для истории, а не только последний.
- Проверить весь путь: сохранение игры → Worker/Collector → архив сервера → подтверждение → очистка очереди в игре.
- Убрать замену неподтверждённых снимков новыми при заполнении очереди.
- При достижении лимита сохранять очередь и приостанавливать новый сбор с понятным сообщением.
- Раздельно показывать ожидание сохранения, отправки и подтверждения; после получения подтверждения счётчик должен уменьшаться.
- Учесть двухэтапный /reload: первый записывает данные игры, следующий читает поступившие подтверждения.
