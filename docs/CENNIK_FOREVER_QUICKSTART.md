# Микрогайд: старт Forever через WIW Hub

Сначала один раз выполнить [развёртывание и очистку](CENNIK_HUB_RELEASE.md).
Обычное обновление очистку не повторяет.

1. **Хаб → Cennik.** Выбрать Forever PvP / Альянс / EU и его рынок AHL.
   Явное имя realm берётся из AHL, если оно есть; иначе — от первого персонажа
   обновлённого аддона выбранного рынка. Retail — отдельный тестовый профиль.
2. **Источники.** Проверить бета-пакет и сохранённый токен AHL.
   Цены проверяются раз в 5 минут; рецепты, FYI и сверка распыления — раз в час.
   Время, добавления, изменения и ошибки видны в «Источники».
   До свежего полного среза бета участвует в расчётах с явной пометкой.
3. **Worker 0.5.0.** Папка Forever и HTTPS-адрес корня хаба, ключ пустой →
   «Сохранить и установить аддон» → подтвердить код в вебе. Нужен совместимый
   Auctionator. После очистки нужны новые ключи. Полностью перезапустить игру.
4. **Два персонажа.** Через меню под миникартой выбрать «Аукционер» / «Крафтер».
   У каждого /reload → дождаться Worker → ещё /reload.
   Один Worker обслуживает два аккаунта одной папки игры; роли можно менять
   после завершения заказов. Крафтеру открыть профессии и считать рецепты.
5. **Первый сбор.** Открыть AH; неизвестного NPC предложить и одобрить по имени/
   координатам в вебе. Синхронизация → /reload → снова открыть AH.
   Дождаться Cennik **«Полный снимок готов»**, затем /reload и подтверждения Worker.
   Веб автоматически пересчитает возможности. При сбое AHL включить
   «Работать без AHledger»; сохранённая бета-подложка также доступна.
6. **Торговля.** Кандидаты → bulk у аукционера → /reload → веб:
   выбрать уточнённые варианты → крафтеру «Самостоятельная закупка» → Worker →
   /reload крафтера → меню «Производство / крафт».
   Возврат товара аукционеру — почта/обмен с подтверждением получения.

Автоцикл включать после ручного прогона: окно аукционера, F8 — макрос /reload,
F9 — игровое «Взаимодействие с целью», NPC в цели, индикатор виден.
Space включается отдельно в Worker; новая случайная задержка 150–400 секунд
выбирается после каждой отправки. Фоновый ввод проверить на настоящем Forever.

Сборщикам дать Collector 0.5.0 и персональные ключи: только сбор и диагностика.
Старый bridge/start_bridge.cmd не запускать.
Проверки выпуска и их границы: [VERIFIED](CENNIK_FOREVER_VERIFIED.md).
